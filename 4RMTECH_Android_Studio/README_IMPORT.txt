4RM TECH - Android Studio Project

IMPORT STEPS
1. Extract this ZIP completely.
2. Open Android Studio.
3. Choose File > Open.
4. Select the extracted folder named 4RMTECH_Android_Studio.
5. Wait for Gradle Sync to finish.
6. If Android Studio asks to install missing SDK/build tools, accept the recommended option.
7. Run the app using an emulator or Android device.

IMPORTANT
- Do not open the ZIP directly.
- Do not open only the app folder. Open the project root folder.
- The project uses applicationId com.fourrmtech.app.
- compileSdk/targetSdk are 34.
